# jod-skills (bundle)

All four skills in one install: `audit`, `hn-daily`, `github-daily`, `oss-status`.

```
/plugin marketplace add jayhemnani9910/jod-skills
/plugin install jod-skills@jod-skills
```

This folder is generated by `scripts/sync-bundle.sh`. Edit the skills under
`plugins/<name>/skills/<name>/`, not here.

See the [root README](../../README.md) for what each skill does and what it needs.
